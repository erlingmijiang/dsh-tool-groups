## 机制现状

- **只编 MCP 工具 + 技能**；所有 DSH 自带工具常驻、不可编组。
- **双名**：英文名是 AI 侧唯一标识（目录条目、`load/list` 参数与返回值、系统提示）；中文名只在设置页展示。
- **组描述列全成员**：目录条目描述包含该组全部技能与 MCP 工具名，便于按名字定位组。
- **单组激活**：`load_tool_group` 自动卸载上一组；加载仅本回合有效。
- **启用开关**：停用组不注册入口、不可加载、成员保持隐藏。
- **系统提示**：常驻一段约 5 行说明，强调「入口不是技能、先 load 再调用」。
